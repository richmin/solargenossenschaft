# solargenossenschaft.ch

Statische Webseite der Solargenossenschaft Zollikofen – ohne CMS, ohne PHP, ohne Datenbank.

- `index.html` – Startseite (Onepager): Anlagen SKW1–SKW4, Mitmachen, Solarstromkauf, Aktuelles, Solarausflug, Über uns, Kontakt
- `assets/` – Logo (SVG/PNG) und Fotos

## Offene Punkte
- Mitgliederzahl bestätigen (zurzeit «[116]»)
- Google Fonts lokal einbinden (Datenschutz, nDSG) statt von fonts.googleapis.com zu laden
- Impressum und Datenschutzerklärung ergänzen
- Statuten und Beitrittsformular als PDF ablegen
- Einverständnis der abgebildeten Personen auf den Ausflugsfotos

## Hosting
Jeder statische Hoster funktioniert, z. B. GitHub Pages (Settings → Pages → Branch `main`, Ordner `/`).
